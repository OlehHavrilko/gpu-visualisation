# GPU visualisation

Статическая 3D-страница (AMD Instinct MI355X).

## Деплой
Push в `main` -> workflow `pages.yml` публикует `site/` на GitHub Pages:
https://olehhavrilko.github.io/gpu-visualisation/

Один раз включить: Settings -> Pages -> Source: **GitHub Actions**.

## Локально
Открыть `site/index.html` в браузере.
